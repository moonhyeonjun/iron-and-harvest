# 씬·입력·애플리케이션 코드

Player/Interaction 어댑터와 작업 흐름을 둔다. 게임 규칙은 systems/, 화면은 ui/를 따른다. 현재 player/(IH-101 이동 controller·임시 Visual), interaction/(IH-102 controller·target), inventory/(IH-110 가방 조율자), gathering/(IH-111 GatherTarget), save/(IH-112 저장·불러오기 조율자), calendar/(IH-120 실시간 달력 어댑터), tests/(검증 맵 연결 스크립트)가 있다. 검증된 기능이 필요할 때만 하위 폴더/클래스를 만든다.
