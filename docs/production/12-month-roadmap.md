# 5. 12개월 개발 로드맵

기준일 2026-10-31. 2026-11~2027-10의 **첫 영지 출시 후보** 계획이며 제국까지의 전체 완성을 12개월 안에 약속하지 않는다. 1인 개발 주 20시간, 연 52주=1,040시간을 임시 가정한다. 이 중 약 780시간은 구현·콘텐츠·검증, 260시간은 재작업·휴식·출시 변수에 남긴다. 아트/음악 외주 여부와 실제 가용 시간은 1개월 차 기록으로 재산정한다.

월별 주차는 작업 묶음이며 달력상의 정확한 주 경계는 아니다. 4/4/5주 묶음을 분기마다 반복해 총 52주다. 지연은 다음 단계의 시간을 자동으로 압축하지 않고 우선순위·출시 시점을 조정한다.

## 매주 반복하는 작업 방식

20시간 기준: 이전 빌드 플레이/우선순위 2시간, 한 기능 구현 8시간, 테스트·수정 4시간, 콘텐츠·표현 3시간, 주간 기록·패키징 1시간, 여유 2시간. 월말 여유 주차와 기능 내 재작업 시간까지 합쳐 연간 여유 예산을 유지한다.

Claude 토큰은 무조건 소진할 예산이 아니다. ① 관련 코드/문서 읽기 ② 범위가 작은 한 기능 ③ 상태 보존 테스트 ④ 실행 확인 ⑤ 주간 기록 순으로 쓴다. 토큰이 남아도 검증 안 된 기능을 늘리지 않는다. 제한에 걸리기 전 현재 diff·실행 명령·실패 로그·다음 단계를 기록한다. 모델별 이용 한도나 비용은 이 계획에서 가정하지 않는다.

매주 산출물은 실행 가능한 빌드 또는 명확한 실행 경로, 변경 파일, 실제 테스트 결과, 알려진 버그, 다음 주 우선순위다. UI 기능은 스크린샷/짧은 영상, 경제 기능은 원인별 결산 로그도 남긴다. 주간 기록 양식은 `docs/templates/weekly-report.md`다.

## Steam 출시까지의 외부 작업

- M2~M4: 실제 연결 루프가 성립한 뒤 개발자 등록·앱 등록 일정을 확보한다. 결제·계정 등록은 별도 사용자 실행/승인 작업으로 남긴다.
- M5~M7: 실제 플레이 화면을 바탕으로 상점 초안·캡슐·영상·지원 플랫폼·언어를 준비한다. 상점 공개는 완료된 자료로 검토한다.
- M8: 첫 영지 완결판인지 장기 게임의 EA인지 정한다. EA는 불완전한 빌드에 붙이는 편의적 표기가 아니며 추가 의무와 공식 안내를 당시 다시 확인한다.
- M10~M11: 배포 파일·스토어 내용·콘텐츠 설문·사용 자산 권리·버전·지원 연락 경로를 점검하고 심사 여유를 확보한다.
- 확인일 2026-10-31 기준 Steam Direct는 첫 출시들의 앱 비용 납부 후 30일 대기 및 공개 Coming Soon 최소 2주 조건을 안내한다. [Steam Direct](https://partner.steamgames.com/steamdirect/)와 [출시 절차](https://partner.steamgames.com/doc/store/releasing)를 출시 준비 시 다시 확인한다.
- 빌드 심사는 통상 3~5영업일이며 최소 7영업일의 준비 여유를 요청한다. 내부 계획은 수정까지 고려해 3~4주를 확보한다. [공식 심사 안내](https://partner.steamgames.com/doc/store/review_process)
- 출시일은 달력 목표보다 심사 승인·저장 안정성·캠페인 완주 관문이 우선한다.

## 범위 조정 규칙

M2 재미 관문 실패: 외교나 추가 콘텐츠로 덮지 않고 수리 루프와 피드백을 2주 더 검증한다. M4 경제가 반복 붕괴: 시설 종류 추가를 멈추고 소비·노동·계절을 조정한다. M6 전투가 예산 초과: 직접 토벌 선택은 유지하되 적/장비/애니메이션 다양성을 줄인다.

먼저 줄일 것은 변형 아트 수, 보조 의뢰 연출, 장비 종류, 부가 UI다. 주민24명·생산망·직접/위임·계절·자립 목표·저장 품질은 축소하지 않는다. 이것도 맞출 수 없으면 출시일을 미룬다. 테스트 시간부터 줄이지 않는다.

## 첫 출시 이후

1. 유지보수와 재미 확인: 저장 호환, 불편 개선, 주민 이야기 추가.
2. 복수 영지: 지역 간 수요·전문화·운송을 먼저 구현한다.
3. 정치: 귀족 관계·봉신 계약·제한된 외교.
4. 국가: 보급 중심 군대·전쟁·왕국 건국.
5. 왕조와 제국: 시간 건너뛰기·계승·정통성·문화권·몰락과 재건.

각 단계는 별도 일정과 비용을 추정한다. 제국 확장의 날짜를 첫해 로드맵에서 확정하지 않는다.
