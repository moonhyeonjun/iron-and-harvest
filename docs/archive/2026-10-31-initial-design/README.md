## 첫 출시의 약속

작은 영지 한 곳에서 주민 24명의 생활과 밀→밀가루→빵 생산을 연결하고, 직접 노동과 위임으로 첫 겨울을 넘겨 자립한다. 첫 캠페인 목표 플레이 시간은 8~12시간이며 완료 후 자유 플레이를 지원한다. 목표 시간은 플레이테스트로 검증한다.

제국 건설은 전체 프로젝트의 최종 목표다. 첫 출시판에 왕조·국가 전쟁·제국 통치를 구현했다고 홍보하지 않는다. 첫 출시를 독립 완결판으로 할지, 장기 전체 게임의 Early Access로 할지는 8개월 차에 지원 역량과 테스트 결과로 결정한다.

## 설계 검증

```sh
python3 tools/check_economy.py
```

이 도구는 생산량·일일 소비·겨울 비축의 가정을 확인한다. 실제 게임 로직이나 게임의 재미를 검증하는 테스트는 아니다. Godot 실행 테스트는 프로젝트 생성 이후 추가한다.
