# 1. 핵심 재미와 플레이 경험

## 플레이어에게 주는 경험

“내가 도왔던 사람이 내 영지를 움직이고, 그 사람과 함께 만든 마을이 국가로 자란다.”

차별점은 생활 활동의 종류나 전략 화면의 크기가 아니라, 같은 주민·같은 자원·같은 사건이 두 방식의 플레이에 걸쳐 지속되는 데 있다. 농부에게 돌려준 도구, 수리한 물레방아, 임명한 관리인이 이후 생산과 주민 대사와 연대기에 함께 나타나야 한다.

## 세 겹의 핵심 루프

| 길이 | 플레이 | 결과와 다음 동기 |
|---|---|---|
| 30초~3분 | 관찰 → 이동 → 대화·수집·작업 | 즉각적인 재료, 문제의 단서, 인물 반응 |
| 하루 약 10분 | 장부 확인 → 한 가지 우선순위 → 직접 행동/위임 → 저녁 결산 | 식량·재정·관계의 변화와 다음 날 과제 |
| 계절 약 2~3시간 | 병목 진단 → 설비·사람 투자 → 계절 위기 → 성과 회고 | 새 생산 방식, 주민의 변화, 다음 성장 목표 |

생활 행동은 경영 화면에 수치로 반영되고, 경영 결정은 생활 공간에서 눈에 보여야 한다. UI 숫자만 바뀌는 기능은 완료로 보지 않는다.

## 첫 30분의 실제 흐름

1. **0~5분:** 성채에서 상속장을 읽고 마을로 이동한다. 관리인 이레나가 “빵이 줄고 있다”는 사실을 알린다. 이동·대화·상호작용을 배운다.
2. **5~12분:** 제분공 토마를 만나 물레방아 파손을 확인한다. 장부에서 밀은 있지만 밀가루가 부족한 이유를 연결한다. 필요한 목재 8개를 직접 모으거나 벌목공에게 요청한다.
3. **12~20분:** 목재를 수리 프로젝트에 납품하고 직접 수리하거나 토마에게 작업을 맡긴다. 직접 작업에는 행동 시간과 기력이, 위임에는 담당 인력과 날짜가 든다.
4. **20~30분:** 하루를 끝내고 결산을 본다. 수리 완료 다음 날부터 밀가루와 빵이 늘어난다. 토마의 대사가 바뀌고 기록에 기여자가 남는다. 농부 미라가 두 번째 밭의 문제를 제안한다.

30분 안에 반드시 연결 루프 한 번을 경험하게 한다. 추가 일과를 강제하여 튜토리얼을 늘리지 않는다. 낮 시간을 일찍 끝내도 된다.

## 모드 전환

- 생활 화면이 기본이다. `Tab`으로 영지 장부를 열고 닫으며 현재 위치로 돌아온다. 전환은 별도 세계 로딩이나 하루 진행을 유발하지 않는다.
- 장부를 열면 세계 시간과 적을 포함한 물리 동작이 함께 멈춘다. 대화·건설 배치·인벤토리·설정도 일시 정지한다. UI 자체는 동작한다.
- 전투 중에도 현황 열람은 가능하지만 위임·건설·거래 실행은 불가하다. 장부로 적을 움직인 채 무적 행동을 수행할 수 없다.
- 장부의 인물·건물을 선택하면 지도에 위치가 표시된다. 순간 이동은 없다.
- 일일 시뮬레이션은 하루 종료 시 한 번 실행한다. 건설·세율·배치 변경은 “다음 결산 적용” 여부를 명시한다.
- 초기에는 `1배속`과 일시 정지, 하루 종료만 제공한다. 월 단위 건너뛰기는 국가 확장 단계에서 중단 조건과 함께 도입한다.

## 직접 해결과 위임의 동일한 목표

`Issue → Project → Contribution → Resolution`을 공유한다. 직접 수리와 NPC 수리는 같은 프로젝트의 남은 작업량을 줄인다. 별도의 보상 퀘스트 두 개로 만들지 않는다.

| 문제 | 직접 행동 | 위임 | 공통 결과 |
|---|---|---|---|
| 제분소 파손 | 목재 채집·납품, 수리 4회 | 목재 예약, 주민 1명 2일 배치 | 동일 제분소 복구, 동일 생산 해금 |
| 식량 부족 | 열매 수집, 개인 텃밭 | 농장 인력·제빵 인력 재배치 | 같은 창고의 식량 증가 |
| 길목의 도적 | 소규모 야영지에서 직접 전투 | 기사에게 식량·금화를 지급해 2일 임무 | 같은 길목 안전도 회복 |
| 일손 부족 | 당일 작업량 보충 | 교육·직무 변경 | 같은 생산 병목 감소 |

위임은 기본적으로 공개된 요구 능력·비용·기간으로 결과를 예측하게 한다. 첫 MVP에서 낮은 확률로 갑자기 실패하는 임무는 제외한다. 준비가 부족하면 시작 불가 사유 또는 확정 부상 비용을 보여준다.

직접 행동은 초반의 긴급 해결에 유용하고 주민과의 관계 및 발견 보상을 준다. 위임은 지속 생산과 규모 확장에 유리하다. 후반에 직접 벌목만으로 국가 수요를 채울 수 없으며, 반대로 고유 주민 이야기와 탐험 발견은 장부 클릭만으로 소진되지 않는다.

## 성장에 따른 역할 변화

| 단계 | 주로 결정하는 것 | 여전히 직접 하는 일 | 진입 조건 초안 |
|---|---|---|---|
| 하급 귀족 | 오늘 먹을 것, 고칠 시설 | 수집·대화·텃밭·수리 | 시작 |
| 자립 영주 | 인력·비축·세금·임명 | 인물 의뢰·새 자원 발견 | 첫 겨울과 자립 목표 완료 |
| 대영주 | 복수 영지의 전문화·교역·봉신 | 현지 조사·협상·원정 | 확장판의 두 번째 영지 |
| 건국자 | 정통성·법률·전쟁·계승 | 귀족·대표자 면담, 중요 탐험 | 왕국 건국 조건 |
| 황제 | 권한 위임·문화권·제국의 안정 | 고향 방문, 후계자와 인물 이야기 | 제국 통합 조건 |

생활/통치 시간 비중의 테스트 가설은 초반 70/30, 영주 45/55, 제국 20/80이다. 비율을 강제하거나 생활 콘텐츠를 잠그지 않는다. 황제의 고향 노동은 관계·문화·개인적 애착을 위한 선택이며 필수 국가 유지보수로 만들지 않는다.

## 실패와 회복

- 하루 적자는 경고이지 패배가 아니다. 식량 부족은 만족도와 생산성에 단계적으로 영향을 준다.
- 초반 연속 3일 결식 시 채집 장소와 구호 요청을 알려준다. 구호는 공짜 반복 수익원이 되지 않도록 캠페인 1회이며 비용은 일시적 명성 하락이다.
- 금화가 0이면 선택 지출과 신설을 막고 유지비 미납을 표시한다. 생산은 즉시 전부 멈추지 않고 해당 시설만 2일 유예 후 휴업한다.
- 기본 난이도에는 시간 제한 패배와 주민의 갑작스러운 영구 사망을 넣지 않는다. 첫해 목표를 놓쳐도 다음 겨울에 재도전한다.

## 기능 채택 기준

새 기능은 ① 하루의 선택을 바꾸는가 ② 주민/마을의 변화를 보이는가 ③ 직접 행동과 위임을 연결하는가 중 하나 이상에 기여해야 한다. 구현·아트·세이브·테스트 비용을 함께 추정한다. 기여가 설명되지 않으면 후순위로 보낸다.

초기 제외: 절차적 대륙, 실시간 대규모 전투, 유전 형질, 복잡한 귀족 작위 체계, 멀티플레이, 마법 연구 트리. 이 기능들을 위한 빈 매니저도 만들지 않는다.

## 재미 검증 관문

- 세로 단면 테스트 5명: 4명 이상이 도움 없이 문제 원인과 자신의 해결 결과를 설명한다.
- 5명 중 4명 이상이 30분 안에 장부↔현장 루프를 완료한다. 실패 시 튜토리얼과 피드백부터 수정한다.
- 자유 세션에서 직접 행동과 위임 모두 실제로 선택되는지 관찰한다. 한쪽만 선택하면 비용·대기·보상 차이를 다시 조정한다.
- “기억나는 주민과 그 이유”를 질문한다. 이름을 못 외워도 역할과 사건을 연결하면 성공 신호다.
- 수치는 작은 표본의 개발 관문이며 시장 성공을 예측하는 통계로 사용하지 않는다.
