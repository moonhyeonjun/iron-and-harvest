# 3. MVP·첫 출시 범위와 UI

## 세 가지 빌드를 구분한다

| 빌드 | 목적 | 범위와 완료 기준 |
|---|---|---|
| 첫 실행 빌드 | 입력과 상호작용 기반 확인 | 이동·충돌·나무 1개·채집·가방, 실제 실행 성공 |
| 핵심 검증 MVP | 재미의 연결 검증 | 3명·4시설·제분소 수리·하루 결산·저장, 30분 연결 루프 |
| 첫 출시 후보 | 독립적인 캠페인 완결 | 아래 전체 범위, 첫 겨울·자립·엔딩·자유 플레이·출시 품질 |

검증 MVP의 3명은 개발 순서상의 축소다. 사용자가 지정한 주민 20~30명과 건물 약 10종은 첫 출시 후보에서 지킨다. 첫 출시 후보를 이하 ‘출시 MVP’라고 한다.

## 출시 MVP 포함/제외

| 영역 | 필수 포함 | 이후 확장 |
|---|---|---|
| 세계 | 마을 1개 + 인접 숲·야영지·소형 폐허 | 다른 영지·세계지도 |
| 인물 | 주민 24명, 그중 핵심 6명, 직무·일정·신뢰 | 혼인·출생·노화·왕조 |
| 건물 | 10종, 지정 부지, 핵심 시설 개선 3종 | 자유 도시 건설·광범위 업그레이드 |
| 경제 | 5 HUD 자원, 아이템 20종, 생산망·세율·수동 거래 | 시장 시세·운송·자동 무역 |
| 생활 | 이동·대화·채집·벌목·광맥·텃밭·수리·장비 | 낚시·요리·여러 던전·희귀 장비 풀 |
| 통치 | 인력 배치·책임자 2자리·예산·위임 프로젝트 | 봉신·정치 파벌·법률 |
| 위험 | 적 2종, 야영지 1개, 직접/위임 토벌 | 군대·전쟁·공성 |
| 이야기 | 주요 의뢰 6개, 보조 의뢰 6개, 사건 12개 | 무제한 랜덤 스토리 생성 |
| 장기 플레이 | 사계절·첫 겨울·연대기·자립 엔딩·이후 자유 운영 | 제국·계승·몰락과 재건 |
| 제품 | 저장3슬롯+회전 자동저장3개, 설정, 키 변경, 튜토리얼 | 모드 지원·멀티플레이 |

한 번뿐인 고유 사건과 반복 사건을 구별한다. 의뢰 12개 중 6개는 인물 고유, 6개는 복구·납품·탐험에 연결한다. 사건 12개 중 8개는 단발, 4개는 조건·14일 재발 대기·선택지로 반복 가능하게 한다. 반복 사건만으로 수십 시간의 새 이야기를 보장한다고 표현하지 않는다.

## 첫 출시 캠페인과 이후 플레이

- 처음 30분: 첫 수리와 결과 확인.
- 약 1~3시간: 두 번째 농장, 생산망 안정, 인물 이야기 2개.
- 약 3~6시간: 시장·기사·폐허, 책임자 임명, 겨울 비축.
- 약 6~10시간: 겨울 대응과 재건 축제 준비.
- 약 8~12시간: 자립 조건 달성, 연대기 회고와 엔딩. 실제 시간은 검증 전 목표다.
- 완료 후에는 운영·미완료 의뢰·개선·사계절 반복을 계속한다. 경제형/주민 신뢰형/방위형 목표 배지를 제공하되 새 콘텐츠가 무한히 생기는 것처럼 홍보하지 않는다.

## 화면 구조

```text
┌ 날짜·계절·시각 ───── 식량/목재/석재/철/금화 ─ 장부 ┐
│                                                   │
│                  생활 월드                        │
│      인물·건물 앞: E 상호작용 + 대상 이름            │
│                                      현재 목표 1개 │
├ HP·기력 ────── 퀵슬롯 1~8 ───── 알림/일시정지 ─────┤
└───────────────────────────────────────────────────┘
```

영지 장부 탭은 `현황 / 생산·건설 / 주민 / 의뢰·위임 / 연대기` 5개로 제한한다. 인벤토리와 지도는 별도 패널이다.

| 화면 | 반드시 보일 정보 | 주요 조작 |
|---|---|---|
| 현황 | 가식 재고, 일일 예상 수지, 부족 원인, 최근 신뢰 변화 | 경고에서 관련 시설/인물로 이동 |
| 생산·건설 | 시설별 입력·출력·배치 인원·휴업 원인·비용 | 인력 조정, 휴업, 지정 부지 선택 |
| 주민 | 이름·가구·직무·능력·신뢰·현재 위치 | 임명, 일정 확인, 지도 추적 |
| 의뢰·위임 | 원인·요구 물자·직접 기여·위임 비용·남은 작업 | 납품, 담당 지정, 취소 결과 미리보기 |
| 연대기 | 날짜·기여자·결과 | 기록 상세, 인물 연결 |
| 거래 | 보유/예약/거래 가능 수량·단가·총액 | 수량 조정과 확정 |
| 하루 결산 | 생산→소비→변동, 막힌 배치, 세금/유지비, 완료 사건 | 상세 보기, 다음 날 시작 |
| 저장/불러오기 | 날짜·버전·플레이 시간·슬롯 상태 | 저장, 불러오기, 손상 시 백업 선택 |

“식량 120” 옆에는 “생산 없을 때 5일분”, 생산을 반영한 예측에는 “현재 조건 지속 가정”을 표시한다. 겨울 도래 등 이미 아는 변화를 무시한 단순 수지를 확정 예보처럼 표시하지 않는다. 재료를 예약하면 보유량과 사용 가능량을 함께 표시한다.

## 조작과 접근성

WASD 이동, E 상호작용, Tab 장부, I 가방, M 지도, Esc 닫기/설정, 숫자 퀵슬롯을 초기값으로 두고 변경 가능하게 한다. 동일 키 충돌은 저장 전에 알린다. 우클릭 취소와 Esc를 함께 지원한다.

월드는 640×360 기준 정수 배율을 우선 검토하되 텍스트 UI는 별도 고해상도 CanvasLayer로 그린다. 1280×720과 1920×1080에서 한국어 잘림·읽기 크기를 확인한다. 자원 경고는 색+아이콘+문자, 글자 배율 100/125/150%, 카메라 흔들림 끄기, 효과음/음악 별도 음량을 제공한다. 컨트롤러 완전 지원·Steam Deck 검증은 출시 필수에서 제외하며 검증 전 지원 표기를 하지 않는다.

## 우선순위와 의존성

| ID | 기능 | 선행 | 인수 조건 |
|---|---|---|---|
| P0-01 | 실행·이동·충돌 | 없음 | 벽 통과 없음, 입력 독립 이동 |
| P0-02 | 상호작용·아이템·가방 | 01 | 동일 지점 중복 획득 방지, 가방 가득 참 처리 |
| P0-03 | 상태·시간·일일 파이프라인 | 02 | 날짜 한 번 증가, 일시 정지 상태 확인 |
| P0-04 | 저장·불러오기 v1 | 03 | 가방·날짜·채집 상태 복원, 손상 방어 |
| P0-05 | 공용 창고·생산·소비 | 03 | 입력/출력 보존, 결식과 병목 표시 |
| P0-06 | 문제·수리·위임 프로젝트 | 04,05 | 직접/위임 같은 결과, 중복 보상 없음 |
| P0-07 | 장부·현장 피드백·튜토리얼 | 06 | 첫 30분 연결 루프 완주 |
| P1-01 | 24명·일정·인력 배치 | P0 | 동일 인물 이중 배치 거부 |
| P1-02 | 10건물·세금·시장 | P1-01 | 자원 부족·예약·미납·취소 동작 |
| P1-03 | 텃밭·사계절·겨울 | P1-02 | 계절 경계 14→15,42→43,56→57 정확 |
| P1-04 | 6인물·의뢰·연대기 | P0-06,P1-01 | 행위자와 결과가 대사/기록에 반영 |
| P1-05 | 탐험·소형 전투·토벌 | P0-04,P1-04 | 직접/위임 사건 상태 동기화 |
| P1-06 | 자립·엔딩·자유 플레이 | P1 전체 | 새 게임부터 엔딩까지 진행 가능 |
| P2-01 | 아트·오디오·접근성·출시 QA | 위 기능과 병행 | 플레이 가능한 기능을 제품 수준으로 정리 |

P0는 핵심 검증 MVP, P1/P2는 출시 MVP의 필수다. 우선순위가 낮다는 이유로 저장·UI 품질을 출시 뒤로 미루지 않는다.

## 출시 차단 조건과 품질 관문

- 새 게임→첫 겨울→자립→계속 플레이를 디버그 치트 없이 완주한다.
- 아이템 복제, 금화 음수, 인력 중복, 결산 중복, 저장 손상, 필수 의뢰 막힘은 출시 차단 결함이다.
- 3개 세이브 슬롯과 자동저장 복구, 저장 중 프로세스 중단, 이전 지원 버전 업그레이드를 검사한다.
- 장부 100회 전환·맵 100회 전환 후 노드/메모리의 지속 누적이 없어야 한다.
- 기준 PC는 M1에 실제 확보한 Windows 테스트 장비를 기록한다. 목표 1080p/60fps, 하루 결산 p95 100ms 이하(24명/20시설)이며 미측정 성능을 보장하지 않는다.
- 56일 자동 시뮬레이션과 2시간 수동 세션은 별도다. 전자는 수치·상태, 후자는 조작·피로·재미를 확인한다.
- 한국어 전체 검수와 영문 문자열 추출을 제공한다. 영어 판매 지원 표기는 실제 번역·검수 완료 후 결정한다.
- Steam 상점의 영상·스크린샷·설명은 배포 빌드의 기능과 일치해야 한다.
