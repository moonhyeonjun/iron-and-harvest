## 아직 검증해야 할 가정

- 주20시간의 실제 개발 가능 시간과 아트/사운드 공급 방식.
- 첫해 목표8~12시간과 하루10분이 대화·메뉴 시간까지 포함해 적절한지.
- 생산 보너스·거래·채집이 겨울 위기를 너무 쉽게 없애지 않는지.
- 직접 해결과 위임 중 어느 하나가 항상 우월해지지 않는지.
- 24명 중 누구를 기억하는지, 6명의 고유 서사가 충분한지.
- 목표 Windows 장비와 실제 지원 OS·언어·입력 장치.
- 왕조 시간과 생활 시간의 연결, 첫 출시의 완결판/EA 구분.
