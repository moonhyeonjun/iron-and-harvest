# 핵심 게임 루프

## 목적·경험

현장에서 주민을 알고 장부에서 문제를 판단하며 직접 해결하거나 사람에게 맡겨 마을의 변화를 확인한다. 두 모드는 같은 자원과 주민 상태를 사용한다.

## 기능과 흐름

관찰/장부 확인 → 원인 조사 → 행동 선택 → 시간/자원/노동 투입 → 생산/신뢰/외형 결과 → 새 목표. 제분소 수리 연결 루프는 첫 검증 시나리오 제안이다.

생활↔통치 전환 키, 메뉴 일시 정지, 하루 결산 방식은 Proposed다. 즉시 순간이동과 시간 소모 여부를 UI에 명시해야 한다. 전환으로 결산·보상이 중복되지 않는 것은 구현 불변식이다.

## 데이터와 관계

Issue(id, target, cause), Project(id, issue_id, status, contributions, reservation), Outcome(event_id, effects, participants)의 초안을 공유한다. 생활 행동과 위임이 같은 Project를 진행하고 건물/생산/인물/연대기에 결과를 전달한다. [기술 구조](../02-technical-design/ARCHITECTURE.md)를 따른다.

## 우선순위·완료 조건

v0.2~0.8의 기능을 v0.9 Alpha에서 연결한다. 먼저 이동/상호작용부터 검증한다. 같은 문제를 직접/위임으로 각각 해결해 결과 일치, 중복 완료 방지, NPC 반응과 장부 변화가 확인되면 해당 루프 완료다.
