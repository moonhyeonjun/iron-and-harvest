# 세계·시간·역사

## 목적·경험

같은 영지에서 계절과 주민의 삶이 변화하고, 플레이어의 결정이 누적된 역사로 남는다.

## 기능

MVP: 작은 마을1개, 성채·농지·숲·물길의 공간, 계절/연도. 장기: 탐험 지역·영토·복수 영지·문화/기술·재난·국가·제국·세대 계승. 마을과 탐험 지역의 실제 경계는 TBD다.

## 데이터와 연결

WorldState(map_ids, estate_ids, flags), CalendarState(day, season, year), Territory(id, owner, resources), ChronicleEntry(event_id, date, actors, facts). 저장은 이름보다 ID를 연결하며 역사상의 인물이 사라져도 기록을 잃지 않게 한다.

생활은 실시간, 영지 일일, 국가 월간, 역사 연간 처리를 검토한다. 달력 길이/월 정의/시간 건너뛰기는 Proposed ADR에 남긴다. 장기 시뮬레이션을 열 때 하루의 소비를 무심코 생략하지 않는다.

## 우선순위·완료 조건

v0.4 계절/농사, v0.8 통합 시간, v0.9 자립 역사. 날짜 경계와 저장 복원, 이벤트 중복 방지, 현재 계절 UI/생산 일치 확인. 세계 확장은 MVP 검증 이후다.
