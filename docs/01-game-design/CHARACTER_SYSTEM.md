# 주민·인물 시스템

## 목적·경험

주민의 이름·일·관계·성장이 영지의 기억으로 남고 플레이어가 인재를 발견해 역할을 맡긴다.

## 기능

MVP: 20~30명 주민, 관리인·기사·상인 등 주요 인물, 직업·능력·성격·욕망·충성/신뢰·배경·관계·기술·명성의 설계. 모든 속성을 첫 빌드에서 동작시키지는 않는다. 초기에는 이름/직무/단순 일정/관계 반응부터 구현한다.

## 데이터와 관계

CharacterDef(id, name_key, role, background), CharacterState(job, skills, trust, relations, household, location_anchor), Relationship(from_id, to_id, value, memories). 일손 배치는 영지, 대화는 생활, 관계 변화는 사건/연대기와 공유한다. NPC 노드가 화면 밖에서 없어져도 인물 데이터는 유지한다.

## 우선순위·완료 조건

v0.2 임시 상호작용 대상 → v0.6 필요한 인력 기반 → v0.7 20~30명 인물 통합. 이름/직무 표시, 중복 배치 거부, 관계 변화 원인, 저장 후 ID/관계 복원, 화면 밖 일정 일관성을 확인한다.
