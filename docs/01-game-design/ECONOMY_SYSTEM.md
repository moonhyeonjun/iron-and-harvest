# 경제·생산 시스템

## 목적·경험

생산망의 병목과 투자 효과를 이해하고 오늘의 소비와 미래의 비축을 선택한다. 자원·경제·군사·정치는 같은 비용을 공유한다.

## 주요 기능

식량/목재/석재/철/금화가 주요 자원이다. 밀→밀가루→빵→주민 식량의 생산 체인을 우선 검토한다. 시설은 인력·원료·생산량·유지비를 가지며 세율 변화가 재정과 만족도에 영향을 준다. 수동 거래는 초기 후보, 자동 물류/변동시장은 확장 후보다.

## 데이터와 연결

RecipeDef(inputs, outputs, work, period), ResourceLedger(owned, reserved, capacity), DailyReport(produced, consumed, tax, upkeep, blockers). 자원 상세 품목은 [아이템](ITEM_SYSTEM.md), 노동은 [인물](CHARACTER_SYSTEM.md), 처리 순서는 [TDD](../02-technical-design/TDD.md)에서 관리한다.

## 제안 수치와 증거

기존 `data/design/economy-baseline.json`은 **설계 실험 전용**이다. `python3 tools/check_economy.py`는 해당 가정의 계산만 확인하며 런타임 게임 구현이 아니다. 24명·정상빵40·소비24·겨울14일·유지비12는 미확정이다. 현 단계에서 런타임 정의로 복사하지 않는다.

## 우선순위·완료 조건

v0.5 생산, v0.6 세금, v0.8 통합. 자원/금화 음수 방지, 예약 보존, 원료·인력·창고 부족 원인 설명, 일일 처리 중복 방지, 계절 조건에서 자립 가능성 확인. 거래 왕복 차익과 무한 보상 경로를 검사한다.
