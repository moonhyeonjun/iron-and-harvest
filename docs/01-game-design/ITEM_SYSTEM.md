# 아이템·자원 체계

## 목적·경험

수집한 재료가 장비·건물·생산·연구·관계에 실제 쓰이도록 한다. 판매가 유일한 목적이 되지 않게 한다.

## 기능과 데이터

범주: 자원·작물·요리 재료·광물·목재·도구·무기·방어구·유물·고서·씨앗·설계도·마법 재료. MVP는 생산·채집에 필요한 최소 품목부터 시작한다.

ItemDef(id, name_key, category, stack_limit, effects), ItemStack(item_id, quantity), InventoryState(owner_id, slots_or_counts, reservations). 개인 가방과 영지 창고 사이 이동은 보존 거래로 처리한다. 동일 물자의 이중 소유·예약 초과·중복 지급을 방지한다.

## 관계·우선순위

v0.3 가방/채집, v0.4 씨앗/작물, v0.5 건설/생산 재료. [경제](ECONOMY_SYSTEM.md)와 [저장](../02-technical-design/SAVE_SYSTEM.md)이 같은 안정 ID를 사용한다.

## 완료 조건

추가·제거·이동·가득 참·부족·저장 왕복에서 수량 보존. 장비와 소비품의 사용 실패 시 아이템이 사라지지 않는다. 삭제된 콘텐츠 ID는 명시 migration 대상으로 남긴다.
