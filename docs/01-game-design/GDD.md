# 게임 디자인 문서

이 문서는 확정 콘셉트와 현재 시스템 설계의 색인이다. 수치는 검증 전 제안이며 기능 구현은 없다.

## 확정 콘셉트와 시작

가난한 하급 귀족이 작은 성채·낡은 마을·부족한 농지·소수 주민을 물려받는다. 도적·야생 동물·경쟁 귀족이 있는 중세 판타지에서 직접 생활과 영지 통치를 연결하고 제국까지 성장한다. 경제·군사·정치·문화/기술이 서로 영향을 준다.

| [LIFE_SYSTEM](LIFE_SYSTEM.md) | 이동·상호작용·채집·개인 농사 | 아이템/시간/인물 |

## MVP

마을1개, 주민20~30명, 건물약10종, 주요자원5종. 이동/상호작용/채집/가방, 농사/건설/생산/세금/주민, 계절/연도. 최종 목표는 자립 가능한 영지. 완료 판단은 [마일스톤](../03-development/MILESTONES.md)과 [작업](../03-development/TASKS.md)에 연결한다.

## 참고 초안과 TBD

[이전 상세 GDD](../design/02-gdd.md)의 가시여울·인물6명·24주민·아이템20종·수치표·첫 겨울·수동전투는 참고 제안이다. 최신 요청이 이를 확정한 것으로 해석하지 않는다. 정확한 콘텐츠 수, 계절 길이, 손실/회복, 임무 실패율, 건설 배치, 첫 출시 형태는 TBD다.

완료 기준: 자립까지 이어지는 루프를 실제 플레이하고 수치/관계/시각 결과가 연결되는 증거가 있어야 한다. 문서만으로 기능을 완료 처리하지 않는다.
