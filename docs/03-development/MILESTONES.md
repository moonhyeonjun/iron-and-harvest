# 마일스톤과 버전

모두 목표 버전이다. 실제 태그/릴리스 결과는 IH-002-VALIDATION의 통합 기록을 따른다. 완료 조건·테스트·리뷰를 충족했을 때 자율적으로 태그/릴리스를 만든다. Foundation은 IH-001 관리 체계와 IH-002 엔진 검증을 모두 충족했다. v0.1.0은 기술 기반 태그이며 게임 제품 출시가 아니다.

| 버전 | 목표·기능 | 의존성 | 완료 조건 | 테스트 기준 | 예상 리스크 |
|---|---|---|---|---|---|
| v0.1.0 Foundation | 프로젝트/문서/Git/관리/빈 씬 | 없음 | 구조·안전 규칙·엔진 고정·import/실행 검증 | 정적 검사·검증기 테스트·실제 엔진 | macOS 빈 씬만 검증; Windows/export/게임 기능은 후속 범위 |
| v0.2.0 Character | 이동·충돌·상호작용 | Foundation | 작은 맵에서 이동/대상 조작 | 입력·충돌·범위·실행 | 조작감·카메라 |
| v0.3.0 Gathering | 채집·가방·초기 저장 | Character | 수집/이동/복원 일치 | 포화·중복·수량 보존·저장 | 아이템 유실/복제 |
| v0.4.0 Farming | 심기·성장·수확·계절/연도 | Gathering | 날짜에 따른 농사 순환 | 계절 경계·로드·중복 수확 | 시간/농사 결합 |
| v0.5.0 Building | 건설·수리·기초 생산 | Farming, 인력 최소 모델 | 재료/작업→시설/생산 | 예약/취소·원료 부족·완료 | 위임/건설 이중 처리 |
| v0.6.0 Estate | 장부·세금·자원·배치 | Building | 수입/지출/인력이 현장 반영 | 미납·세율·할당·UI | 자립 불가능 경제 |
| v0.7.0 Population | 20~30주민·주요 인물·관계 | Estate | 직무/일정/관계의 상태 일치 | 중복 배치·대화·로드 | 인물 콘텐츠 비용 |
| v0.8.0 Simulation | 생산/경제 통합·저장 안정화 | Population | 장기 결산·자원/인력 보존 | 반복 연도·migration·성능 | 밸런스 붕괴·누적 오류 |
| v0.9.0 Alpha | 자립까지 연결 루프 | Simulation | 새 게임→자립 완주·관찰 테스트 | 실제 플레이·실패 회복·UI | 재미/콘텐츠 부족 |
| v1.0.0 Release | 제품 품질·Steam 출시 | Alpha, 권리/심사 | 지원 환경 QA·저장·상점 일치 | 배포/업데이트/복구·심사 | 출시 일정·지원 비용 |

기술 의존성을 위해 NPC의 최소 노동 데이터는 v0.5에 준비하고 고유 서사/일정/주민 규모는 v0.7에서 완성한다. 생산은 v0.5, 통합 시뮬레이션은 v0.8이다. 이를 마일스톤 순서 충돌로 오해해 필요한 최소 기반을 늦추지 않는다.

완료 여부는 [TASKS](TASKS.md)와 [WEEKLY_LOG](WEEKLY_LOG.md)의 증거로 판단한다. 정확한 일정·인력·아트/사운드 공급은 IH-005 TBD다.
