# 마일스톤과 버전

v0.1.0은 확정된 기준점이다. v0.2.0 Character는 [마일스톤 판정](CHARACTER-v0.2.0-VERIFICATION.md)에서 완료 조건 충족과 main 승격을 확인했다. 원격 annotated 태그 v0.2.0은 main `8901bac`에 고정됐다. v0.3.0 이후는 목표 버전이다. 기존 태그v0.1.0 → d176bd7의 로컬/원격 일치를 [재검증 기록](FOUNDATION-v0.1.0-VERIFICATION.md)에서 확인했다. 태그는 보존하고 후속 설계 문서는 별도 커밋한다. 완료 조건·테스트·리뷰를 충족했을 때 자율적으로 태그/릴리스를 만든다. Foundation은 IH-001 관리 체계와 IH-002 엔진 검증을 모두 충족했다. v0.1.0은 기술 기반 태그이며 게임 제품 출시가 아니다.

기술 의존성을 위해 NPC의 최소 노동 데이터는 v0.5에 준비하고 고유 서사/일정/주민 규모는 v0.7에서 완성한다. 생산은 v0.5, 통합 시뮬레이션은 v0.8이다. 이를 마일스톤 순서 충돌로 오해해 필요한 최소 기반을 늦추지 않는다.

완료 여부는 [TASKS](TASKS.md)와 [WEEKLY_LOG](WEEKLY_LOG.md)의 증거로 판단한다. 정확한 일정·인력·아트/사운드 공급은 IH-005 TBD다.

## v0.3.0 현재 관문

IH-110 아이템/가방과 IH-111 채집은 수정·독립 검증까지 done이다. IH-112 초기 저장·복원은 [구현 명세](../02-technical-design/SAVE_LOAD.md)·[수락 조건](IH-112-ACCEPTANCE.md)를 준비한 ready이며 아직 기능이 없다. v0.3.0 완료/태그는 IH-112의 실제 왕복·실패 복구·세대 보존과 기존 회귀/GUI/통합 증거를 확인한 뒤 별도 판정한다.
