# Foundation PR 준비 기록

원격 PR을 생성한 기록은 없다. 최초 원격에 refs가 없어 Foundation 기준점은 PR 없이 초기 commit/push 방식으로 구성한다. 이후 기능은 develop 기반 작업 브랜치와 필요한 PR로 통합한다.

최초 커밋: 957dd3bbdf564c04636b7be082d800f89a458524.
메시지: chore(foundation): establish project structure and development workflow.
관련 작업: IH-001, IH-007. 엔진 검증 IH-002는 별도로 남아 있다.

Git/GitHub 작업은 별도 승인 없이 자율 운영한다. 실제 commit/push/merge 기록과 검증은 [GIT_BOOTSTRAP](GIT_BOOTSTRAP.md)을 참조한다. 이 문서는 원격 PR 링크를 가장하지 않는다.
