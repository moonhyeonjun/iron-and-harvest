# ADR-010: Git/GitHub 자율 운영

## 상태

Accepted. 2026-10-31 사용자 명시 정책 변경. ADR-009의 승인 대기 Git 운영만 대체하며 기존 문서는 보존한다.

## 배경과 대안

매번 승인을 기다리는 방식 대신 검증과 이력 보존을 기준으로 개발 라이프사이클을 자율 실행하도록 사용자가 지시했다. 기존 승인제 유지 / 무제한 이력 변경 / 검증 기반 자율 운영 중 마지막을 채택한다.

## 결정

stage/commit, 로컬·원격 브랜치 생성/전환/병합/삭제, pull/fetch/push, Issue/PR 생성/종료/병합, 원격 설정 변경, 검증된 태그/릴리스를 별도 승인 없이 수행한다. 목적과 완료 조건에 필요한 작업만 수행하며 모든 단계가 필수인 것은 아니다.

Conventional Commits, 작은 의미 단위, 작업 브랜치→develop→안정화→main, 관련 Issue 연결, 원격 반영 확인, 해시·결과 기록을 따른다. 초기 빈 원격의 기준점 구성은 PR 없이 가능하다.

## 안전 경계와 영향

reset --hard, clean -fd, force/force-with-lease, 임의 이력 재작성, 사용자 변경 삭제/덮어쓰기를 기본적으로 하지 않는다. 손실을 분석하고 백업/복구 가능한 대안을 우선한다. 안전한 대안이 없거나 충돌 의도가 불명확하면 사용자 확인이 필요하다.

Git 자율 권한은 게임 완성·태그 기준을 완화하지 않는다. 엔진 검증이 남은 Foundation을 완료 버전으로 태그하지 않는다. Steam 게시/결제/라이선스 결정 권한으로 확대하지 않는다.

## 검증

Foundation 파일 목록·정적 검사·테스트를 통과한 뒤 최초 커밋을 만들고, 원격 refs를 확인하고, 비강제 push 후 SHA를 다시 비교한다. IH-007과 GIT_BOOTSTRAP에 기록한다.
