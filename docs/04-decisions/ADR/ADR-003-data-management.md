# ADR-003: 데이터 관리

## 상태

Proposed

## 날짜

2026-10-31

## 배경

수치·콘텐츠와 로직을 분리해야 한다.

## 검토한 대안

JSON / Godot Resource / 혼합

## 결정

정의·런타임 상태를 분리. 정의 포맷은 비교 후 결정.

## 결정 이유

기존 경제 JSON 실험을 유지하면서 에디터 편의도 평가.

## 단점 및 고려사항

이중 원본 금지, 공유 Resource 변이와 참조 오류 주의.

## 영향

IH-110에서 작은 ItemDef 샘플과 검증으로 선택.

변경 시 이 문서를 삭제하지 않고 후속 ADR로 대체 관계를 기록한다.
