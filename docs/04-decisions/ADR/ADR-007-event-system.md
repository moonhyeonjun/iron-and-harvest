# ADR-007: 이벤트 구조

## 상태

Proposed

## 날짜

2026-10-31

## 배경

생활·경영·UI·연대기 결합을 줄여야 한다.

## 검토한 대안

직접 호출 / signal / 도메인 이벤트 큐

## 결정

작은 명령 경계와 상태 반영 후 이벤트 발행 제안.

## 결정 이유

중복 완료와 재귀 상태 변경을 제한할 수 있음.

## 단점 및 고려사항

범용 이벤트 프레임워크·전체 event sourcing은 도입하지 않음.

## 영향

필요한 첫 프로젝트에서 타입/중복 키 검증.

변경 시 이 문서를 삭제하지 않고 후속 ADR로 대체 관계를 기록한다.
