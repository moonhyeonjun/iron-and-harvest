# ADR-008: 생활과 통치 연결

## 상태

Accepted

## 날짜

2026-10-31

## 배경

사용자는 두 모드가 하나의 세계로 연결되기를 명시했다.

## 검토한 대안

별도 상태 / 공유 세계 상태

## 결정

두 모드가 같은 자원·인물·문제 결과를 사용한다. 구체 구현은 Proposed.

## 결정 이유

직접 행동과 위임의 결과를 플레이어가 이어서 이해.

## 단점 및 고려사항

동일 상태 변경의 중복 처리와 UI 불일치를 막아야 함.

## 영향

IH-170 통합 루프와 각 상태 테스트에서 검증.

변경 시 이 문서를 삭제하지 않고 후속 ADR로 대체 관계를 기록한다.
