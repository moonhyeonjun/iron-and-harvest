# ADR-009: 저장소·Git 운영

## 상태

Accepted

## 날짜

2026-10-31

## 배경

장기 개발과 사용자 변경 보존을 위한 관리 계약이 필요하다.

## 검토한 대안

루트 Godot 프로젝트 / game 하위 프로젝트

## 결정

game/을 Godot 루트로 구성. main/develop 정책과 승인 기반 Git 작업.

## 결정 이유

사용자가 지정한 구조·Git 안전 규칙을 구현.

## 단점 및 고려사항

현재 unborn 브랜치로 main/develop 실체 생성은 최초 커밋 승인 후.

## 영향

도구는 --path game 사용. 기존 문서는 보존하고 신규 문서가 현재 기준.

변경 시 이 문서를 삭제하지 않고 후속 ADR로 대체 관계를 기록한다.
