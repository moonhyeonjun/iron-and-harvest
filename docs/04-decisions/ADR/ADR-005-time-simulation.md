# ADR-005: 시간 처리

## 상태

Proposed

## 날짜

2026-10-31

## 배경

생활 실시간과 대규모 경영 주기가 다르다.

## 검토한 대안

전 프레임 처리 / 주기 처리 / 이벤트 혼합

## 결정

이동 프레임, 영지 하루, 국가 월, 역사 연 단위 검토.

## 결정 이유

전체 NPC/시설을 프레임마다 계산하지 않음.

## 단점 및 고려사항

결산 순서·시간 건너뛰기·계절 길이 TBD.

## 영향

IH-120과 Simulation 마일스톤에서 경계 검증.

변경 시 이 문서를 삭제하지 않고 후속 ADR로 대체 관계를 기록한다.
