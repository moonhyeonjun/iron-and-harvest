## 확정 범위

중세 판타지에서 가난한 영지를 물려받은 하급 귀족이 주민과 마을을 성장시키고, 장기적으로 왕국과 제국을 건설한다. 픽셀 아트, 직접 생활과 통치의 연결, 아이템 수집과 인물의 삶이 핵심이다. 황제가 된 후에도 고향의 생활을 유지한다.

이번 작업은 기반·문서·관리 체계다. 게임 기능은 구현하지 않는다. 초기 MVP는 마을1개, 주민20~30명, 건물약10종, 식량/목재/석재/철/금화, 이동·상호작용·채집·가방·농사·건설·생산·세금·주민·계절/연도이며 목표는 영지 자립이다.

## 문서 권위

사용자 최신 지시 → 승인된 ADR/확정 기획 → 현재 구현·테스트 증거 → Proposed 설계 순으로 구분한다. 구현과 설계가 다르면 TASKS/BUGS에 기록한다. [GDD](../01-game-design/GDD.md)가 기획 진입점, [TDD](../02-technical-design/TDD.md)가 기술 진입점이다.

`docs/design/`, `docs/production/`, `docs/templates/`는 이전 초안/기록을 원문 보존한 참고 자료다. 새 문서 체계가 현재 기준이며 이전의 루트 project.godot/src 경로는 적용하지 않는다. [이전 진입 문서](../archive/README.md)도 보존한다.
