# 로드맵

v0.1.0 Foundation 태그가 존재하며, v0.2.0 Character는 [기능 완료 판정](../03-development/CHARACTER-v0.2.0-VERIFICATION.md)을 통과했다. main CI 성공 후 v0.2.0 태그를 main8901bac에 발행·검증했다. v0.3.0 이후는 목표 버전이며 제품 출시와 구분한다. 사용자 지정 버전 순서는 [마일스톤](../03-development/MILESTONES.md)을 따른다. 버전 번호는 달력 날짜나 구현 시작으로 확정하지 않는다.

## 단계

Foundation → Character → Gathering → Farming → Building → Estate → Population → Simulation → Alpha → Release.

기능은 세로로 검증하되 앞 단계에서 필요한 최소 기반(예: 시간/저장 인터페이스)을 준비한다. v0.8에서 처음 시뮬레이션을 만드는 것이 아니라 v0.5 생산과 v0.6 재정을 통합·안정화한다.

## 12개월 초안과 관계

[이전 12개월/52주 계획](../production/12-month-roadmap.md)은 주20시간, 2026-11~2027-10, 첫 영지 출시라는 가정의 참고안이다. 최신 버전별 관문을 대체하지 않는다. 실제 가용 시간·아트 공급·엔진 검증 후 IH-005에서 다시 산정한다. 해당 문서의 날짜, EA 결정 시점, 플레이 시간은 TBD다.

## 출시 관문

저장 안전·새 게임부터 자립까지 완주·성능/지원 환경·콘텐츠 권리·Steam 심사를 충족해야 한다. GitHub 태그/릴리스는 검증 조건 충족 시 자율 생성한다. Steam 게시/출시 권한은 이번 Git 정책에 포함되지 않는다. Steam 절차의 참고 출처는 [기존 공식 자료](../design/sources.md)이며 제출 시 재확인한다.

## 확장

자립 MVP 검증 뒤 복수 영지→외교/봉신→군대/전쟁→왕조/계승→왕국/제국 순서를 제안한다. 확장 순서와 날짜는 미확정이며 각 단계에서 별도 ADR/작업을 만든다.
