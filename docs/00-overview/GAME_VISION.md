# 게임 비전

## 플레이어 경험

내가 도운 주민이 영지를 움직이고, 그 사람들과 만든 마을의 역사가 국가의 역사가 된다. 캐릭터의 수집·성장과 영지의 생산·관계·정치가 같은 세계의 결과로 이어진다.

## 확정 설계 원칙

- 직접 조사·작업·탐험과 인력 고용·위임이 같은 문제를 해결한다.
- 초반의 생활/생존, 중반의 운영/인재, 후반의 국가/정치/군사를 단계적으로 확장한다.
- 경제·군사·정치·문화/기술의 선택에는 비용과 결과가 있다.
- 주민이 장식으로 머물지 않고 직무·관계·기억·역사를 가진다.
- 작은 마을의 독립적인 재미부터 검증하며 콘텐츠 추가만으로 결함을 덮지 않는다.

## 검증 가설 — Proposed

첫 수리 문제가 현장 대화→재료 확보→직접/위임→생산 재개→주민 반응으로 이어지는지 관찰한다. 초안의 30분 루프·5명 테스트·생활/통치 비중은 확정 목표 수치가 아니다. [게임 루프](../01-game-design/GAME_LOOP.md)에서 평가한다.

신규 기능은 어떤 선택을 바꾸는지, 주민/마을에 어떤 결과를 보이는지, 제작·저장·테스트 비용은 얼마인지 설명한다. 기여가 없는 기능은 보류한다.

## 장기 목표와 현재 상태

제국 건설은 최종 비전이다. 초기 MVP에는 국가 전쟁·왕조 전체를 구현하지 않는다. 생활 활동을 후반 필수 반복 노동으로 강제하지 않는 방향을 검증한다. 마법의 강도·종교·문화권의 상세 규칙은 TBD다.
