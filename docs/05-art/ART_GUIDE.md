# 아트 가이드

## 확정 방향

독자적인 중세 판타지 픽셀 아트. 작은 성채·낡은 마을·농경지·숲·물길·먼 산을 통해 소박한 시작과 장기 성장 가능성을 보여준다. 따뜻하고 아늑한 생활 분위기와 전략 세계의 깊이를 함께 표현한다. 참고 게임의 고유 스프라이트/UI를 복제하지 않는다.

## 제작·데이터 규칙

편집 가능한 원본은 art/source/, 게임에 사용하는 출력은 game/assets/에 둔다. 배포 실행 파일의 exports/와 에셋 출력 디렉터리를 혼동하지 않는다. 에셋마다 ID, 원본, 출력, 제작자/출처, 라이선스, 사용처, 검수 상태를 [ASSET_LIST](ASSET_LIST.md)에 적는다.

리소스 경로는 소문자와 snake_case. 라이선스/출처 없는 외부 에셋을 임의로 추가하지 않는다. 수정/내보내기 방법을 기록해 원본으로 결과물을 다시 생성할 수 있게 한다.

## 우선순위와 완료

기반 검증은 아트 없이 빈 씬이다. 다음 단계 임시 도형→플레이어/상호작용 대상→마을 시설→주민→계절 순서를 제안한다. 크기/방향/가독성·픽셀 정렬·아트 권리·실제 게임 import를 확인해야 완료다.
